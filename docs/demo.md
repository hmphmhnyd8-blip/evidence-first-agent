# 5 分钟讲解与演示

1. 先运行 `python build_database.py` 和 `python demo.py`，说明同一接口如何区分正常值、全部缺失与查无记录。
2. 配置模型与完成建库后运行 `python chat.py`，输入“查询 DEMO-001 的平均航速，并根据项目资料解释缺失值如何处理”。观察 SQLite 与资料工具分别返回什么，检查最终引用。
3. 输入“换成 DEMO-002 呢”，核对数值是否变为 22；再输入“清空”，验证下一轮不继承旧消息。
4. 输入“预测明天的油耗”，检查是否说明工具和资料能力不足，不编造吨数。模型行为可能变化，展示实际结果。
5. 展示 `tests/test_contracts.py`、CI 和开发案例 DEV32 的失败记录：解释为什么一个事实正确的回答仍可能因未满足引用条件而失败。

面试时区分：设计机制、自动测试验证范围、真实模型案例和未完成项。不要将单次成功演示称为稳定正确率。
